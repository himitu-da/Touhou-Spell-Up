# [v0.1.15] - [2025-08-23]
## Added
- 数値型でない型に対してもCalculatePatternを実装できるようにする
    - 例えば、PatternBaseの具象クラスや、Entityなど。
    - パラメータとしてこれを用意しておいて、これをCalculatePatternの引数に渡すことで、CalculatePatternの計算結果をパラメータとして使用できるなど
    - 計算結果のIndexに応じて、代入先パラメータを指定できるようにする
    - CalculatePatternBaseを実現している抽象クラス（ExpressionCalculatePatternBase）を追加
    - ExpressionCalculatePatternBaseを実現している具象クラスの追加
        - GameEntityExpressionCalculatePattern
- AnimatePatternを抽象クラスを追加する（ShootPatternは撃つ方法の責務、MovePatternは移動の方法の責務、AnimatePatternは見た目変化の方法の責務）
    - GameEntity変更、大きさ変更、色変更、回転変更等
- EntityControllerにAnimateを司る部分を追加

- `Color`型の`GameParameter`および`Reference`を追加
- `ScaleAnimatePattern` を追加。エンティティのスケールを時間経過で変化させる。
- `RotateAnimatePattern` を追加。エンティティの回転を時間経過で変化させる。

## Changed
- HotReloadのバージョンアップ
- Bulletのファイル構造を変更
- コーディング規約の更新
- `ChangeColorPattern`が`ColorReference`を使用するように変更し、開始色と終了色を`GameParameter`で動的に指定可能に
- `PatternBase`にmXparserを利用した汎用的な実行条件式 (`_startConditionExpression`, `_endConditionExpression`) を導入
- `EnemyController`が`GameEntityController`のヘルスシステムを正しく継承するようにリファクタリング
- `ChangeColorPattern` を `ColorAnimatePattern` に名称変更。
- `ColorAnimatePattern`, `ScaleAnimatePattern`, `RotateAnimatePattern` に、LerpモードとDeltaモードの2つの動作モードを追加。
    - Lerpモード: 開始値から終了値までを指定時間で変化。
    - Deltaモード: 現在値（または指定された初期値）から、毎秒一定量ずつ変化。Durationが0以下の場合は永続的に変化。
- Deltaモードの開始値にLerpモードの変数を流用していた問題を修正し、Deltaモード専用の開始値変数を追加。
- `MovementState` を `GameEntityState` にリネームし、エンティティの基本的な状態（位置、回転、速度、スケール）を管理するように変更。
- `GameEntityController` が `MovementState` の代わりに `GameEntityState` を使用するように更新。`transform.localScale` は `GameEntityState.Scale` を反映するように変更。
- `PatternBase` および `MovePatternBase` のメソッドシグネチャを `GameEntityState` を使用するように更新。
- `AnimatePatternBase` および `CalculatePatternBase` の `ExecuteImpl` メソッドのシグネチャを `GameEntityState` を使用するように更新。
- `AccelerationMovePattern`, `CurveMovePattern`, `SatelliteMovePattern`, `StraightMovePattern`, `HomingMovePattern` の `ExecuteMove` メソッドのシグネチャを `GameEntityState` を使用するように更新。
- `SequencePattern`, `ParallelPattern`, `BranchPattern`, `LoopPattern` の `ExecuteImpl` メソッドのシグネチャを `GameEntityState` を使用するように更新。
- `ScaleAnimatePattern` が `transform.localScale` を直接操作するのではなく、`GameEntityState.Scale` を変更するように修正。
- `GameEntityController` に `_initialScale` を追加し、Prefabの初期スケールを保持するように変更。`GameEntityState.Scale` は初期スケールに対する倍率として機能するように修正。
- `GameEntityState` と `GameEntityProperty` の責務分離を実施。動的な状態は `GameEntityState`、静的な設定は `GameEntityProperty` で管理するように変更。
- 各エンティティタイプ専用の状態クラスを追加：
    - `PlayerState`: プレイヤー専用の動的状態管理
    - `EnemyState`: 敵の現在体力(`CurrentHealth`)管理
    - `BulletState`: 弾の残り寿命(`RemainingLifeTime`)、攻撃力、プレイヤー弾判定管理
- `GameEntityController` から直接の状態管理を除去し、`CreateState()` 仮想メソッドで型安全な状態作成パターンを導入。
- `BulletProperty` の `LifeTime` を `InitialLifeTime` にリネームし、実際の寿命管理は `BulletState.RemainingLifeTime` で実行するように変更。
- `EnemyProperty` に `MaxHealth` プロパティを追加し、`EnemyController` が `EnemyProperty.MaxHealth` を参照するように変更。
- `GameEntityState` の `Scale` は `ScaleMultiplier` に名称変更し、初期スケールに対する倍率として機能するようにする。
- EmissionShapeシステムをEmissionシステムに統一
    - `EmissionShapeBase` → `EmissionBase` に名称変更し、階層的設計を導入
    - 中間抽象クラスを追加: `PointEmissionBase`, `LineEmissionBase`, `PlaneEmissionBase`
    - 12個の具象クラスを実装:
        - **Point系**: `PointEmission`, `CircleEmission`, `MultiPointEmission`
        - **Line系**: `LineEmission`, `SpiralLineEmission`, `MultiLineEmission`, `SimpleLineEmission`
        - **Plane系**: `PlaneEmission`, `GridPlaneEmission`, `MultiPlaneEmission`, `SimplePlaneEmission`, `SpiralPlaneEmission`
    - 統一されたフォルダ構成: `Core/Pattern/Emission/Point|Line|Plane/` に分類
    - `CreateAssetMenu` パスを統一: `Danmaku/Pattern/Emission/[Type]/[Feature]` 形式
- 関連するGameParameterシステムの更新:
    - `EmissionShapeReference` → `EmissionReference` に名称変更
    - `EmissionShapeGameParameter` → `EmissionGameParameter` に名称変更
    - `AngleModeGameParameter`, `EmissionTimingReference`, `LineOrderReference`, `PlaneOrderReference` を追加
- 新しい順序制御システムの実装:
    - `LineOrder` enum: 8つの線上配置パターン（Skip, CenterOut, CenterIn, Alternating等）
    - `PlaneOrder` enum: 10個の2D配置パターン（Spiral, Radial, Checkerboard, RandomWalk等）
    - `EmissionTiming` enum: 8つのタイミング制御モード

## Fixed
- `ChangeColorPattern`が共有アセット（ScriptableObject）のメンバー変数を更新していたため、複数の弾で同時に実行すると1つの弾しか色が変化しなかった問題を修正
- 弾幕システムのリファクタリング後に発生していた弾の生成・衝突検出・ダメージ処理の問題を修正。`BulletState` による適切な状態管理で弾システムが正常動作するように復旧

## Removed
- `TriggerPatternBase`およびその全ての具象クラス（`TimeTriggerPattern`, `CollisionTriggerPattern`など）を廃止。機能は`PatternBase`の実行条件式に統合
