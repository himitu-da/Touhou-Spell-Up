# [v0.1.12] - [2025-08-13]

## Added
- CalculatedParameterを実装
    - 数式パーサーを追加（mXparser）
    - 責務は、GameParameterの値を計算すること（呼び出されたとき）
- CalculatePatternBaseと各CalculatePatternを実装
    - GameParameterの値を計算するPatternBase
    - これによって、GameParameterの値を計算して、他のGameParameterに渡すことができるようになる
    - Float、Vector2、Bool、Intに対応
    - GameParameterに発射ごとに1ずつ変わる、特定の関数を動く、他のGameParameterの値を参照できる、のような処理を追加する
        - これによって更に柔軟な出現位置やふるまいを実現できる
- GameParameterReference.cs に GameEntityReference, PatternBaseReference, EmissionShapeReference などを追加

## Changed
- 弾の移動速度を修正（5→35）
- GameEntityControllerの計算を、UpdateからFixedUpdateに変更して、ロジックと描画のタイミングを分離
- 全PatternBaseのUpdateをFixedUpdateに変更。時間に依存する処理は、FixedUpdateで行うように変更。時間の計算もTime.fixedDeltaTimeを使用するように変更
- 描画のJitterを減らすために、GameEntityControllerで描画補完を行うように
- AngleParameterで、0～360度の範囲に収めるように変更
- CalculatedParameterを、CompositePattern内で使用できるようにする
    - GameParameterを用いた時間発狂やHP発狂を作れるように
- SequencePattern, LoopPattern, ParallelPattern の pattern フィールドを PatternBaseReference に変更
- ShootPatternBase の _entity と emissionShape フィールドをそれぞれ GameEntityReference, EmissionShapeReference に変更
    - BasicShotPattern, MultiWayPattern, RotatingShotPattern, ScatteringPattern でコンパイルエラーが発生していたため、.Value を介してアクセスするように修正
- Calculate以外のPatternBaseのフィールドを Reference に変更
- GameEntity、GameEntityProperty、GameEntityController、PatternBase、EmissionShape、Image、PrefabのGameParameterReferenceを増やす
- ゲーム内のPattern、Entity、EmissionShape、UI関連クラスのフィールドををReferenceクラスで置き換える

## Fixed
- まだRotatingShotPatternで、DirectionOffsetがまだ加算されていなかった問題を修正
- SatelliteMovePatternで、接線の移動速度の場合、適切に動かなかった問題を修正

## Removed
